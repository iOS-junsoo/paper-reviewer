mixupT5 · 데이터 중심 증강

mixup은 모델도 손실도 바꾸지 않고 데이터를 섞어 일반화를 높이는 증강 기법이다. 무작위로 뽑은 두 학습 예제를 λ 비율로 선형 결합해 "가상의 예제"를 만드는데, 이미지뿐 아니라 라벨도 같은 비율로 섞는다. 이렇게 하면 모델이 데이터 사이 공간에서 부드럽게(선형적으로) 행동하도록 규제된다. 스테퍼로 섞는 과정을 따라가고, 아래에서 λ를 직접 조작해 본다.

직접 조작λ 조작 — 이미지와 라벨이 함께 섞인다

섞는 비율 λ를 직접 움직여 보자. 왼쪽 결합 이미지와 오른쪽 라벨 막대가 항상 같은 λ로 함께 변한다 — 이것이 mixup의 핵심이다. 아래 Beta 분포는 λ가 어디서 뽑히는지 보여준다: α가 작으면 λ가 0 또는 1 근처(거의 안 섞임, ERM에 가까움), α가 크면 0.5 근처(강하게 섞임)에서 주로 뽑힌다.

결합 이미지는 두 색면의 α-blend로 선형 보간을 표현한 것이며, 실제 이미지 데이터가 아니다. 수식(x̃=λxᵢ+(1−λ)xⱼ, ỹ=λyᵢ+(1−λ)yⱼ, λ~Beta(α,α)), α→0이면 ERM 수렴, α=0.2/1 사용은 논문(1710.09412)의 실제 정의다. Beta 곡선은 해당 α의 실제 확률밀도를 계산해 그린 것이다.

왜 잘 될까 — 결정경계가 부드러워진다

논문 Fig.2의 핵심. 두 클래스(파랑·주황) 사이 경계를 비교하면, ERM은 훈련점에 딱 맞춰 급격하고 불규칙한 경계를 그어 데이터 사이·바깥에서 진동한다. mixup은 데이터 사이를 선형 보간해 학습하므로 부드럽고 넓은 전이대를 만들어, 처음 보는 입력에도 안정적으로 반응한다.
